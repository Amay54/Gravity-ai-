# Security Policy

## Supported Versions

We actively update and patch security vulnerabilities in the following releases:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

If you identify a security vulnerability in GravityAI, please do not open a public GitHub issue. Instead, report it responsibly by contacting our security team at `security@gravityai.internal`.

Upon receiving your report, we will:
1. Acknowledge receipt of the vulnerability within 48 hours.
2. Provide an estimated timeline for a patch.
3. Coordinate a public advisory disclosure release alongside the fixed version release.

# Changelog

All notable changes to the GravityAI Enterprise AI Research Operating System are documented in this handbook.

## [1.0.0] - 2026-07-10

### Added
- **Phase 9: Production Release & Telemetry**: Dynamic performance aggregation endpoints (`GET /api/v1/system/performance`), Streamlit telemetry panel dashboard (`4_Performance_Telemetry.py`), optimized multi-stage Docker builds, and GitHub Actions CI/CD workflows (`ci.yml`).
- **Phase 8: Content Studio Suite**: LinkedIn, Twitter (X) thread, executive email, blog, and newsletter generator engines, simulated publishing connectors with approval checkboxes, draft version history database.
- **Phase 7: Professional Report Engine**: ReportLab PDF, Word DOCX, and PowerPoint PPTX slide deck compilers with four premium design templates (Professional, Minimal, Corporate, Dark). Centralized EvidenceStore with APA bibliography citation resolver.
- **Phase 6: Multi-Agent Architecture**: Reorganized specialists package, Agent Bus abstraction, Report Reviewer Agent (6-dimension audit validation & re-execution loops).
- **Phase 5: Scrapers Tool Registry**: Financial analysis, Document intelligence PDF analyzer, Hiring crawler, Stack detector, and Patents explorer.
- **Phase 4: Supabase Cloud & Authentication**: Email/Password and Google OAuth integrations, DB schema persistence, soft deletes, and favorites.
- **Phase 1-3: Core Foundations**: FastAPI endpoints, Streamlit status checkers, and initial worker agent models.
